# 💓 CarePulse – Disease Detection

**CarePulse** is an intelligent mobile application that leverages AI and wearable device data to detect early signs of cardiovascular conditions such as arrhythmia, hypertension, and stress. Designed with accessibility, privacy, and proactive healthcare in mind, CarePulse empowers users to take control of their well-being.

---

## 🚀 Key Features

- 📊 **Real-Time Health Monitoring**  
  Continuously tracks heart rate, SpO₂, ECG, steps, and more from smartwatches and fitness bands.

- 🧠 **AI-Based Risk Prediction**  
  Uses machine learning (CNN, LSTM, SVM) to detect abnormal patterns and predict potential health risks.

- 🚨 **Instant Alerts & Emergency Notifications**  
  Sends real-time alerts when anomalies are detected and notifies emergency contacts if needed.

- 📱 **User-Friendly Interface**  
  Built with FlutterFlow for a smooth, intuitive experience with clear insights and health trends.

- 🔐 **Privacy & Security Focused**  
  Implements AES-256 encryption and complies with GDPR & HIPAA regulations for safe health data handling.

---

## 🛠 Tech Stack

| Layer        | Technologies Used                                                  |
|--------------|--------------------------------------------------------------------|
| Frontend     | Flutter / FlutterFlow (Dart)                                       |
| Backend      | Firebase (Auth, DB), Flask (AI API)                                |
| Machine Learning | Python, TensorFlow, Keras, Scikit-learn                         |
| AI Models    | CNN, LSTM, SVM for ECG and heart rate anomaly detection            |
| On-Device ML | TensorFlow Lite for offline prediction capabilities                |
| Connectivity | Bluetooth Low Energy (BLE)                                         |

---

## 🧩 System Architecture

1. **Wearable Integration**: Smartwatches sync health data via BLE.
2. **Data Processing**: Data is cleaned, normalized, and passed to ML models.
3. **Prediction Engine**: AI detects anomalies and computes risk levels.
4. **Mobile Interface**: Displays health metrics, history, and alerts.
5. **Cloud Services**: Firebase stores user data securely and syncs across sessions.
